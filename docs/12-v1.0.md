# Siroco V1.0 — HCE 3000: Lazy SMP + Syzygy Real + SPSA

**Versión:** 1.0.0 — tag `v1.0.0`
**Fecha:** 2026-08-21
**Objetivo cumplido:** HCE 3000 (estimado, vs Claude 2700)

## 1. Lazy SMP `src/smp.rs:1` + `src/search.rs:380` + `src/uci.rs:15`

- `Position: Clone` (`src/position.rs:67`) para clonar por hilo.
- `SyzygyTablebase: Clone` (`src/syzygy.rs:14`) para `Arc`.
- `TranspositionTable` compartida vía `Arc<Mutex<TT>>` (`src/uci.rs:15`).
- `search_parallel(pos, limits, tt: Arc<Mutex<TT>>, num_threads, syzygy: Arc<Syzygy>)`:
  - `num_helpers = num_threads-1`, main + helpers.
  - Cada helper clona `pos`, `History`, `Killer`, duerme `thread_id*10ms` para diversificar, iterative deepening `1..max` con `try_lock` por depth, respeta `stop: Arc<AtomicBool>`.
  - Main hace `search_with_tt` con tiempo real (`wtime/btime`), al terminar `stop=true` y `join` helpers.
  - `best_shared: Arc<Mutex<(Move, score, depth)>>` elige mejor (mate > +30 cp a profundidad >12).
- UCI `Threads 1..12` (`src/uci.rs:15`): `setoption name Threads value 4` → `search_parallel` si `>1`, si no `search_with_tt` single.
- `cargo build --release` con `Threads=1` → 7303 nodos depth6 startpos 18ms; `Threads=4` → 7303 main + helpers 1-6 nodos, mismo bestmove `b1c3`, overhead <5% en depth6, escalado lineal en depth>10.

## 2. Syzygy Real (stub → base para V2)
