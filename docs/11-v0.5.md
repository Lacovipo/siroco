## 1. Syzygy stub `src/syzygy.rs:1`

- `SyzygyTablebase { path, enabled }` — UCI `SyzygyPath` (`src/uci.rs:15`, `setoption`). Sin ficheros `.rtbw` actúa como stub; con ficheros en V0.6 se cargará `shakmaty-syzygy`.
- `probe_wdl(pos) -> Option<2/1/0>` para ≤5 piezas, perspectiva lado a mover:
  - `K vs K` → draw, `KQ/KR vs K` → win/loss según lado, `KB/KN vs K` → draw, `KBB vs K` → win/loss, resto `None`.
- `wdl_to_score(ply)` → `±29000 ∓ ply`
- Integrado en `search.rs:378` y `qsearch:241` solo si `ply>0 && enabled && count<=5` para no robar `bestmove` en root.
- Test `K1k1Q3 w` con Syzygy: `depth1 nodes 2 → win 28999 pv e1d1` vs sin Syzygy `45 nodes pv e1e4` — poda exacta.

**Bugfix movegen:** se excluía captura de rey (`opp_king` mask en `src/movegen.rs:194`), no contado en perft pero ahora correcto.

## 2. SPSA `scripts/tune.py:1`

- Framework SPSA: `theta_{k+1}=theta_k + a_k*(score_plus-score_minus)/(2*c_k)*delta`
- Parámetros tuneables: `isolated_mg/eg, doubled, bishop_pair, mobility_n/b/r/q, rook_open, king_shield`
- `python scripts/tune.py --list` / `--apply isolated_mg=-14`
- **Aplicado en V0.5:** `isolated -12/-18 → -14/-20`, `doubled -8/-12 → -9/-13`, `bishop_pair 20/40 → 22/42` (`src/eval.rs:230`). Estimado +15-20 elo en finales de peones.
