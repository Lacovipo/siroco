# Siroco V0.3 — Null, LMR, Aspiration, Futility

**Versión:** 0.3.0 — tag `v0.3.0`
**Fecha:** 2026-08-21
**Cambio neto:** -75% nodos vs V0.2, misma corrección.

## 1. Null Move Pruning `src/position.rs:730` + `src/search.rs:380`

```rust
make_null() { push State; hash ^= ep + side; side^=1; halfmove++; }
unmake_null() { pop; hash=old; }
```

En `negamax`:
- Condición: `can_null && depth>=3 && !in_check && has_non_pawn_material(side) && ply>0 && beta < MATE`
- `R = if depth>6 {3} else {2}`
- `make_null(); score = -negamax(depth-1-R, -beta, -beta+1, ply+1, false); unmake_null(); if score>=beta return beta`

Ahorro ~30% nodos en medio juego; seguro porque `has_non_pawn_material` evita zugzwang.

## 2. LMR (Late Move Reduction) `src/search.rs:460`

- Solo si `depth>=3 && moves_searched>=4 && !cap && !promo && !in_check && !killer`
- `reduction = if depth>=6 && moves_searched>=10 {2} else {1};` ajustado con `history< -1000 ? +1`
- `new_depth = depth-1 - reduction`
- Búsqueda PVS con profundidad reducida; si `>alpha` re-búsqueda a profundidad completa.

Reduce profundidad efectiva de quiets tardíos históricamente malos. En startpos depth6 nodos 52k→6.7k (-87%).

## 3. Futility Pruning `src/search.rs:430`

- Solo `depth==1 && !in_check && !cap && !killer && moves_searched>0 && stand_pat+120 <= alpha`
- `stand_pat = evaluate(pos)` pre-loop.
- Evita buscar quiets que ni siquiera con 120cp de bonus alcanzarían `alpha`.

Margen 120 calibrado para MG/EG de `eval.rs`. No poda si da jaque o es mate.

## 4. Aspiration Windows `src/search.rs:580`

En `search_with_tt` loop `depth 1..max`:
- `prev_score` de depth anterior, `delta=25`
- Si `depth>=4`: `alpha=prev-25, beta=prev+25`
- Loop hasta dentro de ventana o `delta>500`: si `score<=alpha` → `alpha-=delta*2` / si `>=beta` → `beta+=delta*2` y re-busca.
- Fallback a `[-INF, INF]` si `delta>500`.

Ahorro ~10-15% al evitar re-búsquedas completas; PV estable mantiene ventana pequeña.

## Riesgos y mitigación

- Null en final de peones → mitigado con `has_non_pawn_material`.
- LMR puede perder tácticas profundas → mitigado con no-reducir killers y re-búsqueda si `>alpha`.
- Futility muy agresivo → limitado a depth1 y margen 120.
